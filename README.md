# QuantumBenchmarks (Qiskit and BQSKit)

This tool can be used to construct random algorithmic quantum circuits, as well as benchmark existing quantum circuits and create new ones to benchmark.  

## Dependencies
    qiskit
    bqskit
Currently working for the latest version of both Qiskit and BQSkit (1.3.2 and 1.2.0 respectively).
